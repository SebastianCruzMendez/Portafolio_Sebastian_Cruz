01_Sobre_mí

SCM

Soy un desarrollador orientado a analizar, construir y ensamblar sistemas eficientes desde cero. Mi especialidad radica en el desarrollo de aplicaciones web robustas utilizando Java y Spring Boot en el backend, conectadas a bases de datos relacionales como MySQL y PostgreSQL.

Tengo una visión integral del desarrollo, complementando mi lógica backend con interfaces dinámicas construidas en JavaScript, HTML, CSS y Bootstrap. Disfruto desarmar problemas complejos para encontrar la solución más óptima, siempre aplicando buenas prácticas y control de versiones continuo.
