# Portafolio Personal - Sebastián Cruz Méndez

Portafolio profesional desarrollado con una estética retro-tech/synthwave, enfocado en destacar proyectos de desarrollo Full-Stack Java, habilidades técnicas y trayectoria formativa.

##  Tecnologías Utilizadas
* **HTML5 / CSS3** (Estructura y estilos personalizados con diseño fluido y orgánico)
* **Bootstrap 5.3.3** (Sistema de rejilla y componentes adaptativos)
* **JavaScript (ES6+)** (Efecto de máquina de escribir, animaciones de scroll e interactividad 3D Tilt)
* **Bootstrap Icons** (Iconografía técnica)
